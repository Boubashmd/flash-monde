# Flash Monde : règles de confidentialité

Flash Monde est un outil personnel qui fabrique des vidéos d'actualité et les publie sur la chaîne YouTube de son propriétaire.

- **Données utilisées** : l'application demande uniquement l'autorisation de mettre en ligne des vidéos sur la chaîne de son propriétaire (`youtube.upload`). Elle ne lit pas les vidéos, les commentaires, les abonnés ni aucune donnée personnelle.
- **Stockage** : le jeton d'autorisation est conservé dans les secrets chiffrés du dépôt GitHub du propriétaire. Il n'est transmis à aucun tiers.
- **Utilisateurs** : l'application n'est destinée qu'à son propriétaire. Aucune donnée d'autres personnes n'est collectée.
- **Révocation** : l'accès peut être retiré à tout moment depuis https://myaccount.google.com/permissions.

Contact : via le dépôt GitHub https://github.com/Boubashmd/flash-monde
